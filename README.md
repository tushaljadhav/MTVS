# MTVS — Mumbai Vidi Tambakhu Sangh Management System

A modern web portal and dashboard for Mumbai Vidi Tambakhu Sangh (मुंबई विडी तंबाखू संघ).

## Features
- **Dashboard (`index.html`)**: Member counts, collection stats, geographical coverage map (Leaflet), recent activity, and quick actions.
- **Member Directory (`members.html`)**: Searchable, filterable list of all registered members with status, area, and digital pass generation.
- **Member Registration (`register.html`)**: Multilingual form with photo upload, geolocation/GPS tagging, and instant QR pass preview.
- **Digital Membership Pass (`pass.html`)**: Printable, downloadable QR-verified ID card.

## Technologies Used
- HTML5, CSS3 (Modern responsive theme, dark/light styling)
- JavaScript (Vanilla)
- Leaflet.js (OpenStreetMap)
- FontAwesome Icons
- Google Fonts (Inter & Noto Sans Devanagari)

## Live Deployment
This project is configured for deployment on Netlify or GitHub Pages with zero build configuration required.
